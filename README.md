# 英语盲听：公开网页外壳

本目录供独立英语训练仓库的 GitHub Pages 使用。发布资源只有 `index.html`、`styles.css`、`app.js` 和 `.nojekyll`；目录另有本说明与忽略规则。仓库不包含训练包、练习记录或个人资料。不得推送原始训练项目或旧的托管准备仓库，也不得修改续记网站。当前仅是本地准备，尚未上传或发布。

页面从手机“文件”读取训练包。训练包与练习记录保存在当前浏览器的 `localStorage`。应用代码没有主动上传练习记录的接口或统计脚本。`pack_id` 是训练材料编号；网页自行生成独立的 `session_id`，同一包可继续已有轮次，也可明确开始复习新轮次。跨天不自动重置。再次练已听目标时，报告会标记复习或既往暴露，不能当作首次盲听证据。候选句跨轮优先选未见过的；若同包复习时都见过，允许在新轮次重新使用，避免被旧去重表挡住。

“导出待回传记录”收集**所有轮次**中尚未确认回传的已完成练习记录，包含稳定 `record_id`、`session_id`、`pack_id`、实际时间和手机本地日期。重复下载会得到相同记录编号，Work 应按 `record_id` 去重。未完成的当前句留在本地进度，完成后才进入日常回传。报告只附这些增量记录、对应训练目标的必要背景，以及供后续制包去重的历次候选句编号，不含全部历史练习详情。

下载 JSON **不会**标为已回传。手动交给 Work 后，点“确认已交给 Work”，从手机“文件”选择刚才实际发送的那份 JSON，再明确确认。网页只标记那份文件列出的记录；期间新增的记录仍待回传。原始练习记录始终保留。回传文件明文包含句子、理解状态、备注和时间，发送给 Work 即进入当前 ChatGPT 使用环境；不要把它或完整备份提交到公开仓库。

“导出完整备份”独立保存全部训练包、候选句、进度、原始记录、回传确认进度和待确认导出清单。“从完整备份恢复”只接受没有记录的浏览器环境，防止覆盖旧记录；也接受早期 v1 备份并保守标记其记录为复习证据。导出后应在手机“文件”中确认文件已保存，并在空白环境实际试过恢复。浏览器网站数据可能被清除，完整备份应另外保管。若本地存储失败，页面持续警告；请先导出完整备份。若旧存储损坏，网页停止写入，可先下载异常原始数据。

用户已决定继续使用现有 `Ocimoc` 账号和 GitHub Pages，以独立仓库发布，并接受与同一 `Ocimoc.github.io` 域名下其他项目共享浏览器存储的风险。**不同仓库和路径不隔离 `localStorage`**；同源其他脚本理论上可以读取这些记录。这个风险已知且不再作为发布阻断项。GitHub 可能记录访问网站产生的网络信息；在线或来源未知的语音可能把朗读文本交给语音服务。页面默认只列浏览器标记为本机的英语声音，在线或来源未知的声音需要主动勾选。

本地模拟测试与 iPhone 真机测试必须分别记录。目标浏览器是 **iPhone 上的 Google Chrome**；电脑本地文件路径不是手机网址。获准发布到新建的独立 GitHub Pages 仓库后，手机应使用实际生成的 `https://ocimoc.github.io/<仓库名>/` 地址。发布后还需在 iPhone Chrome 实测本机英语声音、从“文件”导入、暂停及切 App 和刷新后的保存、增量导出、完整备份与恢复、存储失败提示。未经用户再次确认，不得上传或公开发布。发布前核对 `git ls-files`，只允许网页文件、`.gitignore` 和本说明。

# 英语盲听：公开网页外壳

这是供 GitHub Pages 发布的静态网页目录。发布资源只有 `index.html`、`styles.css`、`app.js` 和 `.nojekyll`；目录另有本说明与忽略规则。不包含训练包、练习记录、个人资料或原项目历史。新建公开仓库时，应只从本目录的独立 Git 历史发布，不能推送原始训练项目或旧的托管准备仓库。

页面打开后，从手机“文件”选择 JSON 训练包。训练包及练习记录保存在当前浏览器的 `localStorage`，页面本身没有提交记录的网络接口，也没有统计脚本。“导出本轮 JSON”只包含当前训练包对应的 session，不按自然日切分；重复载入同一包会继续旧 session，但回传文件的 `candidate_reuse_guard_ids` 仍包含历史候选句 ID。“导出完整备份”保存整个应用状态，包括全部训练包、候选句、进度和记录；“从完整备份恢复”只接受空白浏览器环境，防止覆盖已有记录。训练报告和备份都是明文文件，备份不要误发给 Work，任何导出文件都不应提交到公开仓库。导出后需在手机“文件”中确认保存，并在无数据的浏览器环境验证恢复。

若本地存储失败，页面会显示持续警告，导入训练包不会假称成功。若旧存储无法解析，网页停止写入，以免覆盖原始数据；可先下载异常原始数据，再决定是否用有效备份覆盖。

**发布阻断：不要将此站直接放到 `Ocimoc.github.io` 的另一个项目路径。** 同一协议、域名和端口下的项目在 Safari 中共享 `localStorage` 与 IndexedDB；独立仓库和路径不能隔离训练记录，也会给该域名下的其他应用带来交叉访问风险。发布前须确定独立主机名，并完成实际 iPhone 语音和存储验证。

GitHub Pages 是公开网页，代码可被任何人查看，GitHub 也可能记录访问 IP。浏览器语音是否需要联网取决于手机上的语音服务；页面代码不调用外部语音 API，但可能选择远程语音。Safari 页面与主屏幕图标的本地记录可能分开，换网址也不会自动迁移；需要时先在旧入口导出，再在新入口使用。

发布前检查 `git ls-files`，只允许上述网页文件、`.gitignore` 和本说明。发布后分别核对公开网页及文件清单，并在 iPhone 上测试语音、导入和导出。

# 英语盲听：公开网页外壳

本目录供独立英语训练仓库的 GitHub Pages 使用。网页资源只有 `index.html`、`styles.css`、`app.js` 和 `.nojekyll`；目录另有本说明与忽略规则。仓库不包含训练包、练习记录或个人资料。不要将训练包、导出记录、完整备份或原始训练项目提交到本仓库。

## 当前手机操作

没有训练包也可以先试新版交互：在本地页面点“先用演示包试按钮”，或打开 `index.html?demo=1`。页面会自动载入 5 句虚构演示材料，无需粘贴。演示使用独立的浏览器存储键，不改动正式训练包和记录；演示数据只供试按钮，不交回 Work。在“更多”可用同一演示包重新练一轮。

不发布线上版时，可在电脑上运行 `node tests/preview-server.cjs 8765`，让同一局域网的手机访问 `http://电脑的局域网IP:8765/index.html?demo=1`。预览服务只提供网页所需的三个公开文件；关闭服务即可停止手机访问。局域网 HTTP 不一定允许自动写入剪贴板，遇到这种情况网页会显示完整内容供手动复制，也可下载 JSON。此预览地址与线上网址的浏览器存储不同，正式训练记录不会自动出现在预览中。

页面分为“训练”“材料与记录”“更多”三个入口。首次使用先到“材料与记录”粘贴完整 JSON 或 `BLP1:` 传输码，也可从手机“文件”选 JSON；再试听并确认英语声音。之后在“训练”直接播放当前句，句子默认隐藏。听完只在“马上懂了／后来才懂／还没懂”中点一项，判断立即保存在本机。重听后第一个按钮自动改成“重听后懂了”，网页记录为 `slow`。若先点“先看英文”，自动记为未懂且原因未知。没播放时主动跳过，记为未尝试；播放后主动跳过，记为未懂且原因未知。暂停、离开或切换 App 不会自动产生失败记录。

没懂后先显示英文，约 3 秒后自动出现正确意思；想快点可点“现在看意思”。需要在看意思前检查文字或补充具体卡点时，展开可选项会暂停自动显示。未检查不推断为看字不认识，原因未选则保持未知。已懂时可直接点“播放下一句”，这一次点击会同时结束当前题并播放新句；核对答案与纠正误触是可选操作。最后一题显示“完成这轮”。点击判断后即使暂停或刷新，当前判断也保留在本地进度；完整增量回传只收已走完当前题的记录。

需要重听时，无论盲听阶段还是判断后查看反馈，播放的都是**当前完整句子**。网页不再自动朗读或单独播放目标词。判断后的整句重听次数另记，不改变第一次听懂与否的证据；旧记录中的目标发音字段原样保留。

练完到“材料与记录”复制未回传记录，经聊天中转给 Work；超过 60 KB 时网页提示改用 JSON 文件，不会截断。确认 Work 实际收到并核对后，再粘贴**刚发出的完整 JSON**或选择同一份文件确认。当前没有独立的 Work 回执协议，因此仅凭复制、下载或一个短码不自动确认回传。网页会核对导出编号、记录 ID 顺序和内容校验值；旧导出文件按原有编号清单兼容。Work 应按 `record_id` 去重。“更多”里才有完整备份、恢复和重新练一轮。新字段和旧记录解释见 [数据协议](DATA_PROTOCOL.md)。

页面可从手机“文件”读取训练包，也可粘贴完整 JSON 或 `BLP1:` 开头的传输码。传输码只是把 JSON 编码成不直接显示句子的文本，不能保密；转发到聊天服务后，该服务可能接触训练包内容。本仓库不附带任何训练包。训练包与练习记录保存在当前浏览器的 `localStorage`。应用代码没有主动上传练习记录的接口或统计脚本。`pack_id` 是训练材料编号；网页自行生成独立的 `session_id`，同一包可继续已有轮次，也可明确开始复习新轮次。跨天不自动重置。再次练已听目标时，报告会标记复习或既往暴露，不能当作首次盲听证据。候选句跨轮优先选未见过的；若同包复习时都见过，允许在新轮次重新使用，避免被旧去重表挡住。

“导出待回传记录”收集**所有轮次**中尚未确认回传的已完成练习记录，包含稳定 `record_id`、`session_id`、`pack_id`、实际时间和手机本地日期。重复下载会得到相同记录编号，Work 应按 `record_id` 去重。未完成的当前句留在本地进度，完成后才进入日常回传。报告只附这些增量记录、对应训练目标的必要背景，以及供后续制包去重的历次候选句编号，不含全部历史练习详情。

复制或下载 JSON **不会**标为已回传。手动交给 Work 并确认其核对完成后，在“确认回传成功”粘贴刚发出的完整 JSON，或从手机“文件”选择那份 JSON，再明确确认。网页只标记那份数据列出的记录；期间新增的记录仍待回传。原始练习记录始终保留。回传数据明文包含句子、理解状态、备注和时间，发送给 Work 即进入当前 ChatGPT 使用环境；不要把它或完整备份提交到公开仓库。

“导出完整备份”独立保存全部训练包、候选句、进度、原始记录、回传确认进度和待确认导出清单。“从完整备份恢复”只接受没有记录的浏览器环境，防止覆盖旧记录；也接受早期 v1 备份并保守标记其记录为复习证据。导出后应在手机“文件”中确认文件已保存，并在空白环境实际试过恢复。浏览器网站数据可能被清除，完整备份应另外保管。若本地存储失败，页面持续警告；请先导出完整备份。若旧存储损坏，网页停止写入，可先下载异常原始数据。

用户已决定继续使用现有 `Ocimoc` 账号和 GitHub Pages，以独立仓库发布，并接受与同一 `Ocimoc.github.io` 域名下其他项目共享浏览器存储的风险。**不同仓库和路径不隔离 `localStorage`**；同源其他脚本理论上可以读取这些记录。这个风险已知且不再作为发布阻断项。GitHub 可能记录访问网站产生的网络信息；在线或来源未知的语音可能把朗读文本交给语音服务。页面默认只列浏览器标记为本机的英语声音，在线或来源未知的声音需要主动勾选。

本地模拟测试与 iPhone 真机测试必须分别记录。目标浏览器是 **iPhone 上的 Google Chrome**；电脑本地文件路径不是手机网址。已发布的地址是 `https://ocimoc.github.io/mobile-blind-listening-pages/`。整句重听改动仍需在 iPhone Chrome 上验证；手机端语音、文件下载、切 App 和刷新恢复、备份恢复及存储失败提示也不能由桌面模拟代替。

本地测试：`node tests/flow.cjs` 检查记录状态、旧数据、导出和回传边界；`node tests/mobile-ui.cjs` 用桌面 Chrome 的 390px 窄屏模拟点击主要流程，需本机提供 Playwright。后者是浏览器模拟，不是 iPhone 真机结果。测试材料均为代码内的虚构设备句，不含个人训练包。
